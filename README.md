# MeiWatch2.0

Factory Operations Monitoring System.

## Overview

MeiWatch2.0 is a simulated factory monitoring
application designed to demonstrate:

- Python-based sensor data processing
- PostgreSQL database management
- REST API development with FastAPI
- Automated machine anomaly detection
- Docker-based application deployment
- Automated testing with pytest

All machine and sensor data is synthetic.
No proprietary company information is used.

This is an updated version of MeiWatch with better UI and containerization so it can be deployed across various systems. 

## Technology Stack

- Python
- pandas
- PostgreSQL
- SQLAlchemy
- FastAPI
- Docker
- pytest
